## Bundled pinned sorting index and optional symbol font — 18 October 2026

The app loads `Sources/AetherCore/Resources/GameDataIndex.json` from its bundle. Format version **2** stores descending IDs, localized names in English/German/French/Japanese, and list-level fields for **146,884 rows / 15,275,189 UTF-8 JSON bytes**: Item **50,880**, Recipe **13,892**, Quest **5,373**, ENpcResident **31,142**, Action **45,597**. The selected canonical dataset is `5c744a8d8daafb25` (patch **7.57**) and schema is `exdschema@2:rev:e773c41a90aed788cf4c1c48469fa85618ef01fb`. The sidebar footer displays **Game data · Patch 7.57** from this metadata. Ordinary startup and browsing perform no index scan or latest-version check.

Item levels use `LevelItem`, recipes `RecipeLevelTable.ClassJobLevel`, quests the first `ClassJobLevel`, and actions `ClassJobLevel`; NPCs have no level field. IDs and parallel name/level arrays are validated. Rows named in at least one supported language are included; blank names in the selected language are excluded from results.

Browsing and literal name search filter and sort the entire category before pagination. **Original order** uses descending IDs in both contexts. Name matching is case/accent/width insensitive in the selected default game language, with compatibility normalization for half-width Japanese input. Name sorting uses localized natural numeric collation and ignores private-use icon markers; level sorting is descending. Equal keys use descending IDs. Search continuations are local row IDs, and results are fetched using pinned `rows` batches of up to 50. API batch order is restored locally; omitted/empty rows are skipped while filling pages. Changing sort, language, query, or category resets pagination and cancels/guards obsolete results. Favorites/history retain their saved original ordering, with localized name/level sorting available.

A bounded actor caches at most **12** sorted query contexts, sharing the immutable bundled names/levels; cached ID arrays have at most approximately **4.9 MB** of payload for this dataset's largest category. Runtime filtering/collation needs no API scan. All game-data URLs include the selected dataset, with the fixed schema on sheet/search requests, including related-recipe cursor pages and auxiliary quest data. Assets pin the dataset without a schema. Pins separate cache entries across releases, and missing/invalid bundled metadata produces an error rather than a fallback to `latest`. Dataset/schema pins stabilize game files and field mappings; they do not freeze XIVAPI's HTTP contract or guarantee service availability.

`Scripts/update_game_data.py` is an explicitly invoked local repository tool. It resolves the latest canonical dataset/schema, skips regeneration when pins and format are unchanged, otherwise scans with fixed pins and atomically replaces the compact UTF-8 JSON only after validation. It records all four name projections and levels, and can upgrade an ID-only index even when its pins are unchanged. The resource is committed to the repository and copied unchanged into Xcode and SwiftPM builds. Updating game data requires reviewing and committing the regenerated index and installing a new app release.

The release workflow never generates indexes. Its read-only `--check-latest` step compares both committed pins with XIVAPI metadata and fails on stale pins or inability to complete the check, instructing the maintainer to update/review/commit locally. `Scripts/build_release.sh` keeps its original two arguments, validates the repository index offline, and verifies the packaged resource byte for byte. Project regeneration preserves existing scheme settings and formatting.

Added an optional background startup download of Square Enix's [FFXIV_Lodestone_SSF.ttf](https://img.finalfantasyxiv.com/lds/pc/global/fonts/FFXIV_Lodestone_SSF.ttf). A valid saved font is used first, without a network request, expiry, or revalidation. The **34,388-byte** file stays under `Application Support/AetherAtlas/Fonts/` across launches and app updates, outside normal response-cache eviction. Concurrent startup callers share one attempt. A missing or invalid file permits one download attempt per app session; offline/HTTP/decoding failures silently retain ordinary text rendering and can retry next launch. An unwritable disk still permits use of a successfully downloaded font for that session.

Downloads use an ephemeral, cookie-free session, HTTPS response validation, 10-second request and 15-second resource timeouts, and a streamed **256 KiB** limit. Existing files are read with the same size bound. Core Text validates the expected PostScript name **XIVAXISStdATK-Regular** and the repeatable-quest glyph before a downloaded copy is written atomically. A private data-backed font descriptor supplies the font directly to SwiftUI; no Font Book installation or global registration occurs. Only supported private-use scalars in game names, linked names, categories, metadata, rewards, and formatted descriptions receive the symbol font, at the surrounding text's resolved size. Other characters retain their native fonts, colors, emphasis, selection, and source text. Unsupported/unavailable glyphs keep normal fallback behavior.
